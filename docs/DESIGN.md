# 환생록 — 설계서 (MVP)

> 가제. 밝은 이세계 애니·라노벨 톤의 텍스트 인생 시뮬레이터 + 로그라이트 환생 루프.
> PC 브라우저 우선. 서버 없이 정적 파일로 동작한다.

## 1. 핵심 루프

```
[윤회의 문] ─► [환생 설정] ─► [인생: 매년 반복] ─► [죽음·묘비] ─► [정산]
  메인 화면     가문 + 권능 선택    행동 방침 → 성장 → 사건     사인 도감 등록   환생석 획득
     ▲                                                                      │
     └─────────────── [윤회의 제단] 환생석으로 가문·권능·잔향 해금 ◄─────────────┘
```

## 2. 캐릭터

| 능력치 | 키 | 의미 |
|---|---|---|
| 체력 | vit | 생존, 검술, 노화. 0이 되면 사망한다 |
| 마력 | mana | 마법 판정 |
| 지성 | int | 학문, 계략 |
| 매력 | cha | 설득, 인간관계 |
| 명성 | fame | 사회적 지위. 환생석 정산에 반영된다 |
| 행운 | luck | 모든 판정에 소폭 보정 |

- 범위는 0~100이다.
- **숨은 값**: 업보(karma, -100~100), 플래그(지나온 사건 기록).
- **인연**: 소꿉친구 / 숙적 / 스승 / 반려. 각각 호감도(0~100)를 가진다.
  - 기본으로는 "냉담·호의·애정·집착" 같은 단어로만 보인다.
  - `호감의 눈` 권능이 있으면 수치가 보인다.

## 3. 한 해의 흐름

1. 행동 방침 선택(3세부터, 유지됨): **수련**(체력·마력) / **학업**(지성·마력) / **교류**(매력·명성) / **탐험**(행운·무작위, 위험 사건이 늘어남)
2. 성장: 방침, 연령 보정, 가문, 권능, 직업 보정을 반영한다.
3. 노화: 40세부터 체력이 감소한다. 55세부터 자연사 확률이 붙는다.
4. 사건: 필수 이정표(3세 마력 각성, 15세 아카데미 등)가 우선이다. 이정표가 없으면 확률적으로 무작위 사건이 하나 발생한다.
5. 선택지 판정 (아래 식, 5~95%로 제한)
   ```
   성공률 = 50 + (능력치 - 난이도) × 3 + (행운 - 20) × 0.3 + 권능 보정
   ```

## 4. 인생 단계

| 나이 | 단계 | 주요 이정표 |
|---|---|---|
| 0~5 | 유년 | 탄생, 3세 마력 각성, 5세 소꿉친구 |
| 6~14 | 소년기 | 7세 적성 의식, 숙적 등장, 마차 사고 |
| 15~17 | 아카데미 | 15세 입학시험(용사/마왕 혈통은 16세 각성 이벤트) |
| 18~ | 진로 | 18세 직업 선택 → 승진(1~5단계) |
| 55~ | 황혼 | 회고, 자연사 |

**직업**: 농부, 기사, 궁정 마법사, 상인, 모험가, 성직자, 마왕군, 용사.
- 직업마다 매년 패시브 성장이 있다.
- 전용 위험 사건이 있다.
- 최고 직위(기사단장, 대마법사, **마왕** 등)까지 오를 수 있다.

## 5. 죽음 (MVP 21종)

사인마다 도감 항목과 묘비명을 가진다. 아직 얻지 못한 사인은 `???`와 힌트로만 표시한다.

노환, 병사, 역병, 기근, 마력 폭주, 귀족의 마차, 정적의 독배, 결투, 국경 전쟁, 던전, 산길의 칼, 용의 숨결, 동료의 배신, 용사 파티의 누명, 집착(소꿉친구), 이단 심문, 금지된 실험, 악마의 계약, 마족 토벌, 용사에게 토벌됨(마왕 루트), 마왕과의 동귀어진(용사 루트)

## 6. 환생석 정산

| 항목 | 산식 |
|---|---|
| 세월 | ⌊나이 / 4⌋ |
| 명성 | ⌊명성 / 4⌋ |
| 직위 | 직급 × 6 (최고 직위 +10) |
| 사인 | 처음 겪은 죽음 +15, 이미 겪은 죽음 +3 |
| 극단의 업보 | \|업보\| ≥ 60이면 +5 |
| 목표 | 달성한 목표의 보상 합, 3개 모두 달성 시 +10 |
| 운명 | 운명에 맡긴 삶은 합계의 +20% (올림) |

  - 사건, 죽음, 전투가 생기면 행동 시트가 자동으로 올라온다.
  - 접어두면 그 사건에서는 다시 올라오지 않는다.
- **도트 배율**: 기기 픽셀 기준 정수배라서, 고해상도 폰에서도 화면 폭을 채우면서 선명하다.

## 7-4. 던전·경제·직업 트리 (v0.7)

### 전투력과 승률
- **전투력**: 체력 + 마력 + 0.5×max(체력, 마력) + 0.25×(지성 + 행운) + 무기 공격력 + 방어구 방어력 + 직업 보너스.
  - 직업 보너스: 기사·마왕군 랭크×10, 용사 랭크×15, 모험가·마법사 랭크×6.
- **적 전투력**
  - 일반 사건 전투: 20 + 난이도×2.2
  - 던전 몬스터: 30 + 계층×4
  - 던전 보스: 몬스터의 1.3배. 마왕만 1.4배.
- **승률** = 1 / (1 + e^(−(내 전투력 − 적 전투력) / (0.15×적 전투력 + 10))). 3~97%로 제한한다.
- 전투 선택지와 던전 보스 앞에서는 항상 「전투력 A vs 적 B · 승률 p%」를 보여준다. 다른 판정 확률은 숨긴다.

### 골드 경제
- 출신별 시작 골드가 다르다. 직업과 직급에 따라 매년 수입이 들어온다.
- 성인은 매년 생활비가 나간다. 집이 있으면 면제된다.
- 골드가 마이너스면 **빚**이다. 매년 이자 10%가 붙고, 빚이 커지면 빚쟁이 사건이 일어난다.
- **상점(마을)**: 시간이 흐르지 않는다.
  - 무기·방어구 8단계
  - 소모품: 회복약, 귀환 두루마리, 부적
  - 생활: 집, 농지, 말, 고양이, 큰 가방
  - 교육: 능력치 +5
  - 명성: 연회, 작위, 성
  - 신앙: 헌금
  - 영약: 노화 지연, 능력치
- **가방**: 던전에서 얻은 재료·장비를 팔거나 장착한다. 기본 30칸이다.

### 던전 (시간이 흐르지 않는 별도 모드)
- 12세부터 들어갈 수 있다. 100계층이고 20층마다 지대가 바뀐다.
  - 1~20 초록 동굴, 21~40 해골 미궁, 41~60 용암 심층, 61~80 얼음 심연, 81~100 마계 회랑
- **5층 단위로 내려간다.**
  - 앞의 4층은 무작위 조우다: 몬스터, 함정, 보물상자, 샘.
  - 5번째 층은 보스다. 내려가기 전에 보스의 전투력과 승률, 현재 HP를 보여주고 「내려간다 / 귀환한다」를 직접 고른다.
- **HP**: 60 + 체력×2 + 방어력.
  - 한 해가 지나거나, 회복약을 쓰거나, 여관에 묵으면(골드) 회복한다. 이게 무한 파밍을 막는 장치다.
  - HP가 0이 되면 죽는다. 보스에게 지고 살아남으면 강제로 귀환한다.
- **체크포인트**
  - 한 생 안에서는 클리어한 5층 단위 지점부터 다시 시작할 수 있다.
  - 생이 바뀌면 1층부터다. 윤회의 제단 「심층의 각인」으로 시작 계층을 5층씩, 최대 30층까지 해금한다.
- **100층 마왕**: 쓰러뜨리면 명성 +40, 10만 골드, 전설이 된다. 게임은 계속되고, 이후에도 던전 파밍은 할 수 있다.
- 모험가는 도달 계층에 따라 길드 랭크가 오른다(10/30/50/80층).

### 직업 분기 트리 (공통 줄기 → 가지 → 세부 가지)
```
인생(공통 줄기: 탄생·유년·성인식)
├ 모험가 ─ 길드 랭커 / 던전 공략자
├ 농부 ─ 지주(농지 보유)
├ 상인 ─ 대상회(랭크 3↑) / 파산(빚)
├ 궁정 ─ 기사 · 궁정 마법사 · 문관 ─ 작위 귀족
├ 도둑 ─ 도적 길드 / 전설의 괴도 / 수감자
├ 성직자 · 마왕군 · 용사
```
- 사건은 `branch`(가지 노드)에 속하고, 내가 그 가지에 있을 때만 일어난다.
- **공통 템플릿**: 「기회 · 라이벌 · 위기 · 횡재」 4종 틀을 가지마다 문장과 수치만 바꿔 재사용한다. 공통 요소는 한 번만 정의하고 가지가 이를 물려받는다.
- 가지별 수입원
  - 농사: 안정적이고 날씨에 따라 변동
  - 상인: 투자 — 성공하면 2~3배, 실패하면 빚
  - 궁정: 고난도 판정, 대신 고수입
  - 도둑: 한탕 — 걸리면 몰수·수감, 세 번째면 처형

## 8. 기술 구조

```
src/
  types.ts           데이터 타입 (사건/선택지/효과/조건)
  data/              콘텐츠 — 여기만 늘리면 게임이 커진다
    houses, cheats, jobs, deaths, names, shop
    events/          childhood, youth, adult, career
  engine/            순수 로직 (DOM 없음, 테스트 가능)
    cond.ts          조건 판정
    life.ts          새 인생 / 한 해 진행 / 선택 처리 / 효과 적용
    text.ts          {name}, {friend} 같은 치환
    score.ts         환생석 정산
  meta.ts            영구 저장 (localStorage)
  ui/                화면 렌더링
  gfx/               도트 그래픽 (painter, portrait, scenes, sprites, mapping, stage)
tests/sim.test.ts    무작위 인생 수천 회 자동 시뮬레이션 (오류·밸런스 확인)
```

- **사건 데이터**: `조건 + 가중치 + 본문 + 선택지[판정, 성공/실패 결과]` 형식의 선언형 데이터다. 복잡한 조건이 필요하면 `test: (s) => boolean` 함수를 쓴다.
- **저장**: 메타(환생석, 해금, 도감, 지난 생애)와 진행 중인 인생을 localStorage에 저장한다.
- **조작**: 마우스, 또는 `Space`로 한 해 진행, `1~4`로 선택지 고르기.

## 9. 도트 그래픽

| 항목 | 내용 |
|---|---|
| 방식 | 그림을 코드로 생성 (`src/gfx/`). 예외: 타이틀 원화 `src/assets/title.png`. 애니풍 비비드 스타일(셀 셰이딩, 색 외곽선) |
| 인물 | 도트 지도 방식 (`dotportrait.ts`). 32×32 모양 표(얼굴·몸·앞머리·뒷머리)와 색상표(머리·피부·옷 램프)를 겹쳐 그리고 2배로 확대. 성별·나이·출신·직업 레이어 |
| 시간대 | 낮/노을/밤. 기본은 낮, 노년은 노을, 일부 사건은 밤 |
| 해상도 | 초상화 64×64, 장면 240×135. 화면에서는 정수배로 확대하고 `image-rendering: pixelated`로 선명하게 유지 |
| 렌더러 | PixiJS 8. 그림은 순수 픽셀 버퍼(`Painter`)로 만든 뒤 텍스처로 올림 |
| 애니메이션 | 별, 불빛, 파티클, 안개, 눈 깜빡임 |
| 전투 | 연출형. 판정 결과(엔진)를 먼저 정하고, 결과에 맞는 GSAP 타임라인을 재생 (`battle.ts`) |
| 타격감 | 히트스톱 70ms(치명타 130ms), 흰색 플래시, 스쿼시&스트레치, 넉백, 파티클, 데미지 숫자, 화면 흔들림 |
| 필터 | pixi-filters: shockwave(치명타), glow(마법·성검), glitch+rgb-split(사망), godray(일부 장면) |
| 생동감 | 1px 숨쉬기, 공격/피격 포즈, 디더 장면 전환, 초상화 표정(기쁨·슬픔·부상) |

- **장면 선택 우선순위**: 올해의 사건 → 직업과 방침 → 나이와 가문의 고향
- **전투 조건**: 전투 사건 + 체력/마력 판정을 고른 선택지
