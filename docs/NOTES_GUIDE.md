# 한 해 기록 작성 가이드

**한 해 기록**은 선택지 없이 연대기에 한 줄로 남는 삶의 순간이다(`YEAR_NOTES`). 매년 새해에 나이·직업 등에 맞는 기록이 하나 뽑힌다. 사건 카드(`docs/EVENTS_GUIDE.md`)와 별개다.

> 예: 「처음으로 두 발로 섰다!」(1~2세), 「비가 오기 전날이면 무릎이 시려 오기 시작했다」(52~58세), 「3등급 모험가들을 상대로 마법 이론 강의를 했다」(궁정 마법사 3직급 이상)

## 1. 목표 분량

실제 사람의 생활을 참고해 전 연령에 걸쳐 쓴다. 생존자가 많은 젊은 나이일수록 많이 쓴다.

| 파일 | 나이 | 목표 | 주제 예시 |
|---|---|---|---|
| `src/data/notes/infant.ts` | 0~5 | 40 | 뒤집기, 걸음마, 첫마디, 돌잡이, 이유식, 낮잠, 형제, 동물, 무서운 꿈 |
| `src/data/notes/child.ts` | 6~12 | 60 | 이 빠짐, 글 배우기, 심부름, 친구, 놀이, 다툼, 숙제, 첫 용돈, 축제 |
| `src/data/notes/teen.ts` | 13~19 | 60 | 사춘기, 키 성장, 외모, 진로 고민, 첫 일자리, 짝사랑, 반항, 성인식 |
| `src/data/notes/young.ts` | 20~30 | 60 | 독립, 첫 월급, 일, 연애·결혼, 이사, 실패, 동창, 여행 |
| `src/data/notes/middle.ts` | 31~50 | 40 | 일의 정점, 후배, 자녀, 부모 봉양, 체력 변화, 첫 흰머리, 건강검진 |
| `src/data/notes/elder.ts` | 51~ | 25 | 무릎·허리, 돋보기, 은퇴, 손주, 회고, 오랜 친구의 소식, 정원 가꾸기 |
| `src/data/notes/job.ts` | 직업별 | 직업마다 8 | 아래 직업 id 참고. 직급(`minJobRank`)으로 나눠도 좋다 |

- 직업 id: `farmer knight mage court merchant adventurer thief priest demon_officer hero`
- 같은 나이대 안에서도 범위를 좁게 나눠 쓴다(예: 1~2세, 6~8세). 그래야 나이에 딱 맞는 장면이 나온다.

## 2. 형식

```ts
{ id: 'n0_first_step', minAge: 1, maxAge: 2, once: true, text: '처음으로 두 발로 섰다! 세 걸음 만에 엉덩방아를 찧었다.', tone: 'good' },
{ id: 'n3_spouse_dinner', minAge: 20, maxAge: 30, cond: { hasRel: ['spouse'] }, text: '{spouse:와} 서툰 솜씨로 저녁을 차렸다.' },
{ id: 'nj_mage_lecture', minAge: 25, maxAge: 70, cond: { jobs: ['mage'], minJobRank: 3 }, text: '3등급 모험가들을 상대로 강의를 했다. 반응이 뜨거웠다.', effect: { stats: { fame: 2 } } },
```

| 필드 | 설명 |
|---|---|
| `id` | 유일한 값. 접두사: `n0_` 0~5세 · `n1_` 6~12 · `n2_` 13~19 · `n3_` 20~30 · `n4_` 31~50 · `n5_` 51~ · `nj_` 직업. 소문자·숫자·밑줄만 |
| `minAge` `maxAge` | 나올 수 있는 나이 (양 끝 포함). 나이는 **여기에만** 쓴다(`cond`에 넣지 않는다) |
| `text` | 한두 문장, **90자 이하** |
| `once` | 한 생에 한 번뿐인 이정표(첫걸음마, 첫 흰머리). 범위 안에서 우선 뽑히고, 마지막 나이에는 반드시 나온다 |
| `cond` | 사건과 같은 조건: `jobs` `minJobRank` `houses` `gender`(`'m'` `'f'`) `hasRel` `flags` `stats` `owns` 등 |
| `weight` | 뽑힐 가중치(기본 1). 흔한 일 1~2, 드문 일 0.3~0.5 |
| `tone` | `good` `bad` `normal`(기본) |
| `effect` | **아주 작게만**: 능력치 ±2~4 (능력치는 0~200), `mood`, `stress` ±5. 돈·인연·플래그·죽음은 쓰지 않는다(사건의 몫) |

- 같은 기록은 8년 안에 다시 나오지 않는다. `once` 기록은 한 번만 나온다.
- 기록이 남을 확률: 30세 이하 85%, 31~50세 55%, 51세 이상 35%.

## 3. 문장 규칙

- **톤**: 밝은 이세계 애니 톤을 바탕으로 **현실의 생활감**을 담는다. 몸의 변화, 일상의 작은 기쁨, 서툰 실수, 계절.
- **문체**: 반말 서술체(`~했다`, `~이다`). 주어 「나」, 「당신」은 생략한다.
- **판타지 양념**: 검·지팡이·마법·던전·길드·모험가 같은 소재를 자연스럽게 섞는다. 현대 물건(휴대폰 등)은 쓰지 않는다.
- **성별**: 주인공 성별은 무작위다. 「그녀」, 「그」를 쓰지 않는다. 성별에 따른 일(변성기, 수염 등)은 `cond: { gender: 'm' }`처럼 조건을 건다.
- **인연 토큰**: `{friend}` `{rival}` `{mentor}` `{spouse}`를 쓰면 **반드시** `cond: { hasRel: ['spouse'] }`처럼 그 인연 조건을 건다. 조사는 `{spouse:와}`, `{friend:이}`처럼 쓴다.
- 그 밖의 토큰: `{name}` `{house}`(출신) `{title}`(직함).
- **겹치지 않게**: 같은 파일 안에서 비슷한 장면이 반복되지 않게 소재를 넓게 쓴다.

```bash
npm test        # tests/notes.test.ts 가 id·나이·길이·토큰 조건·효과 크기를 검사한다
npm run build
```
